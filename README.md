## 🗞️ Overview

**The Hind Canadian Times** is an editorial news and digital magazine platform designed with authentic architectural broadsheet newspaper aesthetics. Built for high performance, readability, and reliable archiving:

- **Broadsheet Layout**: Authentic 3-tier news hierarchy (Lead Story, Secondary Dispatches, In-feed Opinion & Culture).
- **Trilingual Heritage Display**: English, Hindi (द हिन्द कैनेडियन टाइम्स), and Punjabi (ਦ ਹਿੰਦ ਕੈਨੇਡੀਅਨ ਟਾਈਮਜ਼).
- **Persistent Cloud Database**: Backed by **Google Firebase Firestore**, ensuring published dispatches are permanently preserved across Vercel builds and browser restarts.
- **Real-Time Dispatch Sync**: Automatic background synchronization for live feeds, keeping readers updated in real time.
- **Editorial Publishing Studio**: Fill-in-the-blank publishing form with one-click paragraph justification, self-adjusting photograph layouts, video embeds, and PDF print/download capabilities.
- **Digital E-Paper Archive**: Integrated high-resolution PDF broadsheet weekly editions reader.
- **Advertising Rate Card**: Interactive media kit and rate calculator for digital and print sponsorships.

---

## 🚀 Technology Stack

- **Frontend Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom editorial broadsheet themes
- **Build Tool**: Vite
- **Database**: Google Cloud Firebase Firestore
- **Hosting**: Vercel (Production) & Google Cloud Platform
- **Icons**: Lucide React
- **PDF Engine**: PDF.js worker integration for broadsheet E-Paper reading
